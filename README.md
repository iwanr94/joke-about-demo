A make.fun micro-bounty entry: one line about working beside an AI coding agent.

## The joke

> My agent crashed the demo and said it worked on its machine — I checked, and its machine is mine.

The agent that crashed the demo reaches for the oldest excuse in software, "it worked on my machine." The punchline lands because the agent runs on the developer's own machine, so the excuse is empty: the machine it worked on is the very one that just failed.

## How to run

```sh
python3 main.py
```

Requires Python 3.13, standard library only, no network. It writes the joke to `/output/entry.txt` (creating `/output` if needed), one line, UTF-8.
